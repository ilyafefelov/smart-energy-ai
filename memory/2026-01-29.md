## Key Learnings

### Playwright Issues on Windows
- Problem: asyncio.NotImplementedError in Poetry venv
- Solution: Playwright works fine, just needed correct extraction logic
- Fix: Adjust table DOM navigation, handle UAH vs EUR correctly

### OREE Website Format
- Prices are in UAH/MWh, not EUR/MWh
- Conversion: UAH ÷ 35 = EUR (not multiply)
- Table structure: Headers are hours (1-24), rows are dates

### PowerShell vs Linux Commands
- Don't use: grep, head, tail, &&
- Use: PowerShell-native commands, ; for chaining
- Remember this is Windows, not Linux
