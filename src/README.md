# src

Primary backend runtime and Dagster asset code for the active system.

This is the main backend surface for current runtime work. Dagster loads from `src.definitions`, and reusable extraction targets should generally land under `src/data_pipeline/` rather than re-expanding large orchestration modules.

## Working Guidance

- Treat `src/definitions.py` as the active Dagster entrypoint.
- Use `src/cli.py` as the unified CLI for all standalone operations.
- Keep shared data shaping, fallback generation, and validation helpers under `src/data_pipeline/`.
- Prefer keeping `src/assets/` focused on orchestration and asset-contract boundaries instead of embedding heavy helper logic directly in asset modules.
- For local-stack behavior and operations context, pair this folder with `docs/technical/` and `docs/deployment/` references.

## CLI Usage

The unified CLI provides access to all major operations:

```bash
# Show available commands
python -m src.cli --help

# Ingest weather data from Open-Meteo
python -m src.cli ingest-weather --latitude 50.45 --longitude 30.52

# Ingest electricity prices from OREE Ukraine
python -m src.cli ingest-prices

# Run energy optimization
python -m src.cli optimize --scenario Normal

# Train RL agent
python -m src.cli train-rl --train-days 7 --timesteps 2400
```

## Key Components

### Orchestration (`definitions.py`)
The main Dagster entry point that defines all assets, jobs, and schedules.

### Data Pipeline (`data_pipeline/`)
Reusable data ingestion and transformation helpers:
- `ingest_weather.py` - Open-Meteo weather data ingestion
- `ingest_prices.py` - OREE Ukraine price data ingestion
- `optimization_schedule_inputs.py` - Input preparation for optimization

### Optimization (`optimization/`)
Battery scheduling optimization algorithms:
- `baseline_dp.py` - Dynamic programming baseline optimizer
- `milp_scheduler.py` - MILP-based scheduler

### Physics (`physics/`)
Battery models and economic calculations:
- `economics.py` - LCOS and economic modeling
- `battery_lfp.py`, `battery_nmc.py`, etc. - Battery chemistry models
