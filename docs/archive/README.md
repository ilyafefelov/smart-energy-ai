# docs/archive

Reference-only archive for superseded plans, cleanup bundles, and older documentation snapshots that no longer belong in the active docs surface.

- Keep active runbooks, architecture references, and current operator guidance under `docs/`, not here.
- Move dated phase plans, completion reports, obsolete cleanup notes, and older architecture snapshots into this archive instead of leaving them beside active docs.
- Do not create README files inside every archive bundle unless a task explicitly needs that level of historical indexing.
