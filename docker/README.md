# docker

Container and local orchestration configuration for the active Dagster + MLflow development stack.

This folder holds the Dagster instance settings, the workspace loader for `src.definitions`, the local database bootstrap SQL, and the Python dependency sets used by container-oriented workflows.

## Key Files

- `dagster.yaml` configures the Dagster instance to use PostgreSQL-backed storage plus the cron scheduler in container-oriented deployments.
- `workspace.yaml` loads `src.definitions` as the active Dagster code location from `/app`.
- `init-db.sql` bootstraps the local PostgreSQL databases and users for Dagster and MLflow.
- `requirements-dev.txt` keeps notebook, test, lint, and local developer tooling dependencies together.
- `requirements-prod.txt` keeps the Dagster, MLflow, storage, and serving packages needed for deployed or containerized runtime use.

Keep this folder aligned with `docker-compose.yml` and the local stack launch scripts instead of treating it as an archive for old container experiments.
