# tests

Automated validation suites for runtime, scripts, and cleanup guards.

This folder holds focused validation for backend runtime behavior, integration boundaries, dashboard API surfaces, and maintenance regressions.

## Working Guidance

- Prefer the smallest test scope that can falsify your change before widening to broader suites.
- Keep unit-level behavioral contracts in `tests/unit/` when extracting helpers from compatibility-sensitive modules.
- Use integration and e2e layers for cross-surface behavior checks, not as a substitute for targeted unit coverage.
- Keep test fixtures and shared setup in `conftest.py` minimal and explicit so slices remain easy to validate independently.
