# deploy/systemd

Systemd unit templates and environment scaffolding for running Dagster services under Linux process supervision.

These files are for host-managed service installs, not for the local development flow described in `AGENTS.md`.

## What Lives Here

- `dagster-webserver.service` starts the Dagster webserver against `src.definitions` using values from `/etc/smart-energy-ai/dagster.env`.
- `dagster-daemon.service` starts the Dagster daemon after the webserver service is available.
- `dagster.env.example` is the environment template for `DAGSTER_HOME`, the module path, the service port, and the virtualenv command locations.

## Setup Notes

- Replace `__SERVICE_USER__`, `__SERVICE_GROUP__`, and `__REPO_ROOT__` in the service files before installing them.
- Copy `dagster.env.example` to `/etc/smart-energy-ai/dagster.env` and adjust the paths for your target host.
- Install the rendered service files into your systemd unit directory, reload systemd, then enable and start the webserver and daemon units.
- Expect logs to flow to the journal because both units send stdout and stderr to systemd.
